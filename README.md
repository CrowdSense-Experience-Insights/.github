# CrowdSense · `.github`

Organisation-level defaults for [CrowdSense](https://github.com/CrowdSense-Experience-Insights).

| Path | What it does |
| :-- | :-- |
| `profile/README.md` | The public organisation profile shown at [github.com/CrowdSense-Experience-Insights](https://github.com/CrowdSense-Experience-Insights). |
| `brand/` | Logo, mark, avatar and the brand token sheet. Reference these by raw URL from any repo in the org. |
| `SUPPORT.md` | Default support pointer inherited by every repo in the org without its own. |

The members-only repo map lives in the private `.github-private` repo, so this file stays public-safe.

CrowdSense is a product of [Artefact Group](https://github.com/artefactgroup). Its sibling is [AdmitMe](https://github.com/AdmitMe-io).
