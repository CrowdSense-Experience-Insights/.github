# Support

**Product and account questions:** [hello@crowdsense.events](mailto:hello@crowdsense.events)

**Bugs in a public repository:** open an issue on that repository. For the Meshtastic forks, check whether the bug also exists upstream at [meshtastic/web](https://github.com/meshtastic/web) or [meshtastic/web-flasher](https://github.com/meshtastic/web-flasher) and report it there first if it does.

**Security:** email [hello@crowdsense.events](mailto:hello@crowdsense.events) with `SECURITY` in the subject line. Please do not open a public issue for a vulnerability.

CrowdSense is engineered and operated by [Artefact Group](https://artefactgroup.au).
